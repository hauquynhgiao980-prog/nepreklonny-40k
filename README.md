# «Последний курс „Непреклонного“» — карты первого акта

Карты, видео-петли, тайлы, токены и звуки для ваншота по Warhammer 40,000 в Foundry VTT 13 (система dnd5e, модуль `nepreklonny-40k`).

## Порядок сцен

| № | Локация | Что происходит | Папка |
|---|---|---|---|
| 1 | Тюремный блок | Герои просыпаются в стазис-камерах: замки разомкнулись, по коридору ходят сервиторы-смотрители, восьмая камера заперта и искрит | [01_prison_block](01_prison_block/) |
| 2 | Пост охраны | Кабинет дежурного с попутчиками-смертниками, запертая допросная с черепом-протоколистом, хранилище вещей и улик | [02_guard_post](02_guard_post/) |

| 4 | Шлюпочная палуба | Разбитые капсулы, турель бьёт по движению, выживший матрос Варро | [04_lifeboat_deck](04_lifeboat_deck/) |

## Общее для всех карт

- **Сетка.** У полных файлов 128 px на клетку, у лёгких — 64 px (половинное разрешение). Число клеток у пары одинаковое.
- **Петли** длятся 16 с и замкнуты без скачка, Foundry крутит видео-фон по кругу сам. Красные аварийные лампы на всех картах дышат в одном такте (4 с), поэтому при переходе между сценами ритм не сбивается.
- **Полные или лёгкие.** Полные (`…_2304x3072`, `…_3072x2304`, `…_4608x3072`) — для хорошего железа. Если у игроков тормозит, берите лёгкие с тем же именем и вдвое меньшим размером.
- **Координаты тайлов** указаны в пикселях карты от её левого верхнего угла. Проще всего поставить сцене поле (Padding) 0, тогда они совпадают с X и Y в настройках тайла. На лёгкой карте все координаты и размеры тайлов делятся на 2.
- **Прозрачность.** Тайлы-вставки — WebM VP9 с альфа-каналом (пролом, турель, череп) или PNG. Тайлы-вырезы на шлюпочной палубе непрозрачные: это кусок карты целиком.
- **Двери на картах не нарисованы.** Стены и двери ставятся в Foundry, в проёмах с жёлтыми полосами.

## Как залить на сервер

Склонировать репозиторий в папку данных Foundry, например в `Data/maps40k`. После этого отдать папку пользователю, от которого работает Foundry:

```bash
cd /home/ubuntu/foundryuserdata/Data
git clone https://github.com/hauquynhgiao980-prog/nepreklonny-40k.git maps40k
sudo chown -R ubuntu:ubuntu maps40k
```

Если репозиторий закрытый, нужен ключ развёртывания только на чтение. Тогда клонировать по адресу `git@github.com:hauquynhgiao980-prog/nepreklonny-40k.git`.

Обновить: `git -C maps40k pull`. В Foundry файлы будут видны по путям вида `maps40k/03_transit_hall/hall_etap_anim_2304x3072.webm`.
