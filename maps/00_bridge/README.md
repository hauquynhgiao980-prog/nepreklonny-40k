# 0. Мостик — пролог

Сюда нужно положить видео мостика. В репозитории их нет: они лежат только на сервере, в старой папке модуля.

| Что положить | Откуда |
|---|---|
| `bridge_intact_2176x3840.mp4` — целый мостик, фон сцены «Пролог. Мостик» | Скорее всего `bridge_upscaled_00001_.mp4` из старой папки модуля |
| `bridge_broken_2176x3840.mp4` — разбитый мостик с капсулой в витраже, для финала следующих актов | Скорее всего `bridge_upscaled_00002_.mp4` |

Какой из двух файлов целый, проверьте на глаз. Сцена ждёт видео 2176×3840: 17×30 клеток по 128 px. Если размер другой, поправьте ширину и высоту в настройках сцены.

Пролог идёт без бросков: игроки смотрят, как капитан обесточивает «второстепенные системы» и в витраж летит абордажная капсула.
